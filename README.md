# Particle Physics Calculators, Diagram Generator, Amplitude Calculator, LaTeX Generator, Sympy Generator

Lightweight web-based tools designed to assist particle physicists with calculations, diagram generation, LaTeX, sympy, and amplitude evaluation.

---

## Features

- **Scientific Calculator:** Perform high-energy physics numerical computations, constant evaluations, and custom mathematical functions directly in the browser.
- **Feynman Diagram Generator:** Construct, visualize, and inspect Feynman diagrams with automated graph layout and image export.
- **LaTeX Export:** Export generated diagrams to clean LaTeX code for papers and presentations.
- **Amplitude & Cross Section Tools:** Compute decay kinematics, amplitudes, and related quantities.
- **Sympy Code:** Get the sympy code required to calculate amplitudes.
- **Customizable Theories:** Easily extend or modify particle dictionaries, interaction vertices, and custom functions to support beyond-the-Standard-Model.
